# Monster Hunting Rules Vault

An **Obsidian-ready monster-hunting reference** for a 5e campaign built around the loop:

**Contract → Research → Prepare → Track → Confront → Break Parts → Slay/Capture → Carve → Craft → Upgrade**

> [!note]
> This vault is an original table-use rules reference inspired by monster-hunting gameplay. It is not a transcription of *Heliana's Guide to Monster Hunting*.

## Design Goal

Monsters should feel like **targets to study**, **bosses to dismantle**, and **sources of progression** instead of bags of hit points that drop unrelated treasure.
